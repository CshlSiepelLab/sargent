PROGRAM: sargent [Sparse ARG-based ENcoding of Traits]

USAGE: sargent [OPTIONS] <phenotypes> <input.trees> [<geno_prefix>]

DESCRIPTION: Fit a Bayesian sparse linear mixed model for a quantitative
trait that combines the effects of typed SNPs with a random effect derived
from an ancestral recombination graph (ARG).  Phenotypes are modelled as
y = X*beta + u + eps, where X*beta captures typed-SNP effects under a
sparse, BayesR-like mixture prior, and u ~ N(0, sigma_g^2 K) is a random
effect whose covariance K is the span-weighted expected genetic
relationship matrix (eGRM) of the ARG.  The full model is called SARGENT;
omitting the ARG term gives a SNP-only model (SARGENT-S) and omitting the
SNP term gives an ARG-only model (SARGENT-A).  With --predict, sargent
also predicts phenotypes for a held-out test set.

TYPICAL COMMANDS:
    Fit the model (using the example files in the examples/ directory of
    the source distribution, which illustrate the input formats):
        sargent --stage1-gibbs --joint --uniform-arg -o toy_fit \
            examples/toy.phen examples/toy.trees examples/toy

    Fit the model and predict phenotypes for held-out individuals:
        sargent --stage1-gibbs --joint --uniform-arg --predict -o toy_pred \
            examples/toy.phen examples/toy.trees examples/toy

ARGUMENTS:
    <phenotypes>
        Phenotype file, with one value per non-comment line (by default,
        the last whitespace-separated field; see --pheno-col).

    <input.trees>
        Tree sequence file (tskit .trees format) representing the ARG.

    <geno_prefix>
        Prefix for PLINK files (<prefix>.bed, .bim, .fam) containing the
        typed genotypes.  Omit when using --ts-geno.

MAIN OPTIONS:
    --help, -h
        Display this help message and exit.

    --version, -v
        Display the current version number and exit.

    --outroot, -o <prefix>
        Prefix for output files (default "sargent").

    --pheno-col, -C <N>
        Read phenotypes from 1-indexed column <N> (default: last column).

    --ts-geno, -G
        Take genotypes from the tree sequence rather than from PLINK
        files.

    --threads, -T <N>
        Limit all thread pools (OpenMP and BLAS) to <N> threads.  If not
        given, SARGENT_THREADS, OPENBLAS_NUM_THREADS, MKL_NUM_THREADS, or
        OMP_NUM_THREADS is used, in that order.

    --silent, -z
        Omit progress updates to the terminal.

MODEL FITTING:
    --joint
        Estimate the SNP effects and the ARG variance component jointly
        by stochastic EM (recommended).  By default they are estimated
        sequentially, SNP effects first.  Requires --uniform-arg.

    --stage1-gibbs
        Estimate SNP effects by Gibbs sampling (recommended).  By default
        a faster mean-field variational approximation is used.

    --uniform-arg, -U
        Use a single ARG variance component on the span-weighted eGRM
        (recommended).  By default each local tree receives its own
        weight (see EXPERIMENTAL/LITTLE USED).

    --gibbs-iter <N>
        Number of Gibbs sweeps (default 3000).

    --gibbs-burn <N>
        Number of burn-in sweeps (default 1000).

    --precompute, -X
        Force a rebuild of the cached eigendecomposition of the ARG
        kinship matrix (see OUTPUT FILES).  Normally the cache is built
        and reused automatically.

PREDICTION:
    --predict
        After fitting, predict phenotypes for a held-out test set and
        write accuracy measures for each model variant (sargent,
        sargent_s, sargent_a, and snp_lmm, a standard GRM-based LMM) to
        <outroot>.predict.json.  Requires PLINK genotypes.  The full ARG
        must list the training individuals first and the test individuals
        last.  Input and output paths default as follows, and may be set
        explicitly:
          --full-trees <path>     ARG for training + test individuals
                                  (<geno_prefix>.full.trees)
          --test-geno <prefix>    test genotypes (<geno_prefix>.test)
          --test-pheno <path>     test phenotypes (<geno_prefix>.test.phen)
          --predict-out <path>    output (<outroot>.predict.json)

    --model <name>
        Compute only the named variant: sargent, sargent-s, sargent-a,
        snp-lmm, or all (default all).  Stages not needed for that variant
        are skipped.

OUTPUT FILES:
    <outroot>.beta.tsv
        Posterior mixture-component probabilities and expected effect
        size for each typed SNP.

    <outroot>.w2.tsv
        Posterior weights for each local tree (per-tree model only).

    <outroot>.summary.json
        Heritability (h2_snp, h2_arg, total h2), residual variance, and
        basic statistics for the run.

    <outroot>.predict.json
        Prediction accuracy for each model variant (with --predict).

    <trees_prefix>.gall
        Cached eigendecomposition of the ARG kinship matrix, written next
        to the .trees file and reused by later runs.

EXPERIMENTAL/LITTLE USED:
    --sequential, -Q
        Fit sequentially (the default without --joint); has no effect.

    --snp-only, -S
        Fit the SNP term only.

    --arg-only, -A
        Fit the ARG term only.

    --em, -E <N>
        After a sequential fit, run <N> iterations of joint variational
        coordinate descent.

    --stage1-cv <K>
        In sequential fitting, cross-fit the SNP term over <K> folds
        before fitting the ARG term to the residual.

    --mode, -M <name>
        Operational mode; only "predict" (the default) is implemented.

    --pi0, -P <val>
        (Per-tree model) Prior expected fraction of local trees with
        zero weight.

    --ws2-l1 <lambda>
        (Per-tree model) Fused-lasso penalty shrinking per-tree weights
        toward a common level (default 0).

    --ws2-l2 <lambda>
        (Per-tree model) Fused-lasso penalty on differences in weight
        between neighboring trees (default 0).

    --nprobe, -N <N>
        (Per-tree model) Number of probe vectors for stochastic trace
        estimation (default 10).

    --branch-select
        (With --predict) Add variants sargent_w and sargent_wf, which
        augment the eGRM with a kinship matrix built from the top-scoring
        individual ARG branches.
          --select-k <N>        number of branches to keep (default 25)
          --select-trees <N>    number of local trees to scan (default
                                200; 0 = all)

    --stack
        (With --predict) Add a variant (sargent_stack) that combines the
        SNP and ARG predictions with weights estimated by cross-validation.

    Environment variables:
        SARGENT_STAGE1_RESTARTS=<N>   restarts of the variational SNP fit
        SARGENT_S2_VFCAP=<x>          variance cap in the variational fit
        SARGENT_POLYAK_BETA=0         disable averaging of beta
        SARGENT_LEARN_SCALE=1         learn the mixture-prior scale
        SARGENT_GIBBS_SEED=<n>        Gibbs random seed
