PROGRAM: sargent

USAGE: sargent [OPTIONS] <phenotypes> <input.trees> [<geno_prefix>]

DESCRIPTION: Fit a Bayesian sparse linear mixed model incorporating ancestral
recombination graphs (ARGs).  Phenotypes are modelled as y = X*beta + u + eps
where X*beta is a BayesR fit to typed SNPs and u is a random effect whose
covariance is a weighted sum of local-tree kinship matrices from the ARG.

By design, the model prioritises typed SNPs: the BayesR fit explains as
much variance as possible (h2_snp), and the ARG-derived random effect picks
up additional "missing" heritability not captured by the typed SNPs
(h2_arg).  This sequential interpretation is well-defined even though a
classical fixed-vs-random decomposition is not identifiable.

ARGUMENTS:
    <phenotypes>
        Phenotype file.  Each non-comment line should contain one phenotype
        value (by default, the last whitespace-separated field on the line
        is used; use --pheno-col N to pick a specific 1-indexed column,
        which is helpful for files with multiple replicate columns or ID
        columns).

    <input.trees>
        Tree sequence file (.trees).  Used for local-tree covariance matrices
        and, when --ts-geno is given, as the source of genotypes.

    <geno_prefix>
        Prefix for PLINK BED files (<prefix>.bed, <prefix>.bim, <prefix>.fam).
        Required unless --ts-geno is specified.

MAIN OPTIONS:
    --help, -h
        Display this help message and exit.

    --version, -v
        Display the current version number and exit.

    --silent, -z
        Omit all progress updates and per-iteration output to stderr.

    --ts-geno, -G
        Obtain genotypes from the tree sequence file rather than a BED
        file.  When this option is given, <geno_prefix> must be omitted.

    --snp-only, -S
        Run Stage 1 (BayesR fit to typed SNPs) only.  Produces
        <outroot>.beta.tsv but not <outroot>.w2.tsv.

    --arg-only, -A
        Run Stage 2 (ARG random-effect inference) only, skipping Stage 1.
        SNP effects are set to zero.  Produces <outroot>.w2.tsv but not
        <outroot>.beta.tsv.

    --pi0 <val>, -P <val>
        Prior expected fraction of null segments (0 < val < 1).  Sets a
        Beta(1, pi0/(1-pi0)) hyperprior on the activation probability phi,
        giving prior mean phi=1-pi0 (e.g. --pi0 0.9 gives prior mean
        phi=0.1, favouring 90% null segments).  Default: Beta(1,1).

    --outroot <prefix>, -o <prefix>
        Set the output file prefix (default: "sargent").  Output files
        are named <prefix>.beta.tsv and <prefix>.w2.tsv.

    --pheno-col <N>, -C <N>
        1-indexed column to read from the phenotype file (default: 0,
        meaning the LAST whitespace-separated field on each line).
        Useful for multi-column phenotype files of the form
        "family_id  indv_id  y1  y2 ... yK", where you would pass
        --pheno-col 3 to select y1, --pheno-col 4 to select y2, etc.

    --mode <name>, -M <name>
        Choose the operational mode (default: predict).  Modes:
          predict   - the main pipeline.  Default fit is sequential
                      (Stage 1 BayesR on typed SNPs, then Stage 2
                      per-tree REML EM for the ARG random effect).
                      Use --em N (N >= 1) for sequential followed by N
                      joint-EM polish iterations on (beta, ws^2, sigma^2).
                      Outputs .beta.tsv, .w2.tsv, .summary.json with
                      h2_snp (variance explained by SNP fit) and h2_arg
                      (additional variance captured by the ARG).
          localize  - per-window decomposition of h2_arg across the
                      genome (not yet implemented; see ROADMAP.md Phase 7).

ALGORITHMIC VARIANTS (for systematic comparison):
    --uniform-arg, -U
        Replace Stage 2's per-tree REML with a single shared variance
        component on the uniformly-weighted kinship K = (1/S) sum_s G_s.
        Equivalent to fitting ARG-BLUP with a single tau^2.  Useful when
        per-tree weights are unidentifiable.

    --em <N>, -E <N>
        Run sequential SARGENT (Stage 1 + Stage 2) and then N polish
        iterations of joint variational coordinate descent on
        (beta, ws^2, sigma^2), starting from sequential's posterior.
        Each polish iteration does ONE V-solve, ONE damped BayesR beta
        sweep, ONE REML EM step on ws^2, and ONE damped multiplicative
        sigma^2 step.  Default: 0 (sequential only).  Cannot be combined
        with --sequential, --snp-only, or --arg-only.

        The polish trajectory is monitored: if sigma^2 changes by more
        than 5 percent in one iteration (a signature of BayesR mixture-
        component snapping that destabilises the EM dynamics), the iter
        is reverted and the polish stops.  In practice this yields a
        few iterations of meaningful improvement over sequential when
        n_indiv * n_trees is small enough for the cold-start basin to
        be narrow, and a clean revert otherwise.

        Phase 4.5 (2026-05-21) made joint EM usable at scale by warm-
        starting from sequential rather than from beta=0.  The earlier
        cold-start variant degenerated on cases with ~thousands of
        local trees (sigma^2 collapsed; h2_arg saturated at 1).  See
        ROADMAP.md Phase 4.5 for the full diagnosis.

    --sequential, -Q
        Forces the two-stage Stage1->Stage2 pipeline.  This is the
        default behaviour and the flag is currently a no-op; it is kept
        for explicit-documentation purposes and for scripts written
        when joint EM was briefly the default.  --snp-only / --arg-only
        also imply sequential.


OUTPUT FILES:
    <outroot>.beta.tsv
        SNP-effect estimates.  Written after Stage 1 (or when both
        stages are run).  Columns: gamma_1 ... gamma_K  E_beta, where
        gamma_k is the posterior probability that SNP j belongs to
        mixture component k, and E_beta is the posterior expected value
        of beta_j.  One row per polymorphic SNP.

    <outroot>.w2.tsv
        Segment-weight estimates.  Written after Stage 2 (or when both
        stages are run).  Columns: rho_1 ... rho_M  E_ws2, where rho_m
        is the posterior responsibility of component m for segment s, and
        E_ws2 is the posterior expected value of w_s^2.  One row per
        local tree (segment).

    <outroot>.summary.json
        Coherent record of the fit: mode, h2_snp, h2_arg, h2 (total),
        sigma2, plus context (n_indiv, n_variants, n_trees, etc.).
